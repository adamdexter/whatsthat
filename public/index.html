How to get Google OAuth credentials (one-time, ~10 min)
  1. Go to console.cloud.google.com and create a project (e.g. "whatsthat").
  2. In APIs & Services → Library, search for Google Sheets API and click Enable.
  3. In APIs & Services → OAuth consent screen: choose Internal if you have Google Workspace (recommended — no verification needed, tokens never expire). If it's a personal Gmail, choose External, then add your own email as a Test user.
  4. In APIs & Services → Credentials, click Create credentials → OAuth client ID, application type Desktop app.
  5. Copy the Client ID and Client secret into the fields above.

Note: with an External consent screen left in "Testing" mode, Google expires the connection every 7 days — you'll just need to click Connect again. Internal (Workspace) connections don't expire.
